# Contributing

Thank you for your interest in Fio.

Fio is maintained as a personal project and is **not accepting external
contributions at this time**. This includes code, documentation, design,
translations, and other changes. Please do not open pull requests; unsolicited
pull requests will be closed without review.

The repository is public so the implementation can be inspected, learned from,
forked, and reused under the terms of the [Apache License 2.0](LICENSE).
This contribution policy applies only to merging changes into this repository
and does not restrict any rights granted by the license.

If GitHub Issues are enabled, they may be used to report a reproducible bug.
An issue does not create a support commitment or place a request on the
project's roadmap.
